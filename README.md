## 🚀 How It Works

```text
  [ 1. Upload Website ]  ───▶  [ 2. Preview & Edit ]  ───▶  [ 3. Download .ZIP ]
  ZIP, folder, or files        Live WYSIWYG sandbox          Upload to WordPress
```

1. **Upload Your Website** — Drop a `.zip` archive or select a folder/files containing your HTML, CSS, and JS assets.
2. **Preview & Edit in Sandbox** — Test navigation menus, edit page text live, and inspect the generated WordPress template structure.
3. **Download & Install** — Export your theme `.zip` and upload it directly under **`Appearance > Themes > Add New > Upload Theme`** in WordPress.
